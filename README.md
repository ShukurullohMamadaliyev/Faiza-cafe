# 🍽️ Faiza Cafe — Telegram Mini App & Bot

Zamonaviy **Faiza Cafe (Rishton)** uchun ishlab chiqilgan to‘liq interaktiv **Telegram Mini App (Web App)** va **Telegram Boti**.

![Faiza Cafe Logo](public/logo.png)

## 🌟 Asosiy Imkoniyatlar

- 📱 **Mobile-First Dizayn:** iOS va Android qurilmalarida Telegram ichida tabiiy mobil ilova kabi ishlaydi.
- 🎨 **Faiza Cafe Brendingi:** Shohona to‘q zumrad (`#0D3B2E`), nafis tilla (`#D4AF37`) va ishtaha ochar yangi yashil (`#059669`) ranglar uyg‘unligi.
- 🍕 **Haqiqiy Menyu (45+ taom):** 
  - 🌭 21 xil Fastfud (Oddiy, Tandir va Pishloqli lavashlar, Chizburgerlar, Korolevskiy xot-dog, Klabb-sendvichlar, Pita, Shaurma va h.k.)
  - 🍕 6 xil Pitsa (har biri Сред., Бол., Мега o‘lchamlarda: Qazili pitsa, Pepperoni, Palermo, Margarita, Go‘shtli, Assorti)
  - 🥩 Issiq taomlar & Shashlik setlari (Kotletlar Chiz, Syrniy Beyti, Doner tarelka, Cho‘g‘da pishgan shashlik)
  - 🥗 Salatlar (Sezar, Mujskoy kapriz, Olivye, Grecheskiy, Shakarob)
  - ☕ Ichimliklar & Desertlar (Fresh limonad, San-Sebastian chizkeyk, Latte, Qahvalar)
- 🛒 **Interaktiv Savatcha va Bottom-Sheet:**
  - Taom ustiga bosganda qo‘shimchalar (pishloq, sous, go‘sht) tanlash imkoniyati.
  - Kartochka ustidagi `[-] 1 [+]` hisoblagich.
  - Jonli suzuvchi (floating) savatcha indikatori.
- 🛵 **Yetkazib berish rejimlari:**
  - *Yetkazib berish* (Bepul yetkazib berish xizmati bilan!)
  - *Olib ketish* (Filialdan olib ketish)
  - *Kafeda* (Stol raqami bo‘yicha buyurtma)
- 💳 **To‘lov turlari:** Naqd, Payme, Click, Uzum Bank.
- 📊 **Oshxona / Admin Panel:** Tushgan buyurtmalarni bosqichma-bosqich boshqarish (*Yangi ➔ Oshxonada ➔ Yo‘lda ➔ Yakunlandi*).
- 🤖 **Telegram Bot:** `@faizacafe_rishton_bot` bilan to‘liq integratsiya (Kutib olish, Buyruqlar, Lokatsiya va WebApp menyu tugmasi).

## 🚀 Ishga Tushirish

### 1. Web ilovani ishga tushirish:
```bash
npm install
npm run dev
```
Yoki Windowsda `start-dev.bat` fayliga 2 marta bosing.

### 2. Telegram Botni ishga tushirish:
```bash
node bot.js
```
Yoki Windowsda `start-bot.bat` fayliga 2 marta bosing.
